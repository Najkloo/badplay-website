1. Usuń ze starego repo CAŁĄ zawartość, szczególnie folder .github/workflows/ oraz stare pliki package.json/webpack.config.js.
2. Wgraj pliki z tego archiwum bezpośrednio do głównego katalogu repozytorium.

4. Branch: main, folder: / (root).
5. Zapisz.

Ta wersja jest statyczna. Nie wymaga Node.js, npm, Webpacka ani GitHub Actions.
