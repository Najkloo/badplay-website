# BadPlay Website

Projekt przygotowany do publikacji na GitHub Pages.

Po wrzuceniu projektu do repozytorium GitHub workflow automatycznie:
1. zainstaluje zależności przez `npm ci`,
2. wykona `npm run build`,
3. opublikuje katalog `dist/` na GitHub Pages.

Nie trzeba wrzucać `node_modules` ani `dist`.
